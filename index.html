// The Problem

10 million people die from cancer
every year.

The SAVI-2020 library contains 1.75 billion synthesizable molecules. Screening even a fraction against a single protein target requires resources available only to the largest pharmaceutical companies. Most promising candidates are never tested.

Meanwhile, billions of dollars of GPU compute burns electricity solving mathematical puzzles that help no one.

01
Mine

Your GPU runs Boltz2 — the same molecular docking AI used by MIT and Recursion Pharmaceuticals — screening drug candidates against validated cancer targets.

02
Validate

Independent validator nodes re-score every submission using real Boltz2 GPU inference. No fake scores get through. 2-of-N consensus required.

03
Earn

04
Discover

All results stored permanently on Solana blockchain. Open to researchers worldwide. LIFE Compute asserts no IP over discovered molecules — findings belong to humanity.

// Get Started

3 steps.
Under 5 minutes.

If you can play modern games, you can mine $LIFE. Minimum: NVIDIA GPU with 8GB+ VRAM, 16GB RAM, Ubuntu 20.04+ or Windows 10/11.

1
Download

Choose your platform:

↓ Windows .exe ↓ Windows .msi ↓ Linux AppImage ↓ Linux .deb ↓ macOS .dmg ↓ HiveOS .tar.gz

Or install via CLI:

curl -sSL https://raw.githubusercontent.com/life-compute/miner/main/install.sh | bash
2
Connect Your Solana Wallet
~/.life-compute/bin/life-compute wallet connect
3
Start Mining
docker run -d --gpus all --name life-compute-miner -v ~/.life-compute:/root/.life-compute ghcr.io/life-compute/miner:latest
